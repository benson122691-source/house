# 賣房還是出租？租售比較與價格模型

這是 15 分鐘專題的程式碼與簡報。專題用新北市政府公開的租賃、買賣實價資料訓練兩個迴歸模型，再將同一間房的預測租金與售價放進 10 年資產情境比較。

## 專案內容

- `src/train_models.py`：資料清理、特徵工程、模型訓練與租售財務試算。
- `src/crawler_demo.py`：單頁 HTML 爬蟲示範，抓取可由靜態 HTML 讀取的標題、描述和 JSON-LD。
- `results/model_results.json`：這份簡報使用的模型指標與示範試算結果。
- `presentation/rent-vs-sell-presentation-final.pptx`：最終簡報。
- `data/raw/`：放置下載的 CSV；原始資料不放在 GitHub。

## 安裝與執行

需要 Python 3.10 以上。於專案根目錄執行：

```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
# macOS / Linux: source .venv/bin/activate
pip install -r requirements.txt
```

從資料來源下載新北市租賃與買賣案件 CSV，分別存成：

```text
data/raw/rentals.csv
data/raw/sales.csv
```

再執行：

```bash
python src/train_models.py
```

結果會寫入 `results/model_results.json`。資料欄位名稱需與新北市資料集的 CSV 欄位一致；官方資料集更新後若欄位有變，需對應調整 `prepare_frame()`。

## 資料來源

- [新北市不動產實價登錄資訊－租賃案件](https://data.gov.tw/dataset/173898)
- [新北市不動產實價登錄資訊－買賣案件](https://data.ntpc.gov.tw/datasets/ACCE802D-58CC-4DFF-9E7A-9ECC517F78BE)

資料集由新北市政府地政局提供，採政府資料開放授權條款第 1 版。請在報告或再利用時標示資料來源與擷取日期。

## 模型設計

程式分別預測租金和售價，兩個模型共用地區、面積、屋齡、樓層、格局和交易年月等可用特徵；租金模型另用房型、家具，售價模型另用車位資訊。

- **租金目標**：月租金除以建物坪數，單位為元／月／坪。
- **售價目標**：買賣單價換算，單位為萬元／坪。
- **輸入變數**：行政區、建物型態、主要用途、建物面積、屋齡、所在樓層、總樓層、樓層比例、房／廳／衛數、管理、電梯與交易年月。租金另含出租型態及家具；售價另含車位價格與車位有無。
- **比較方法**：中位數基準、Ridge Regression、Random Forest。按交易日期排序，前 80% 訓練、最新 20% 測試，避免隨機切分讓較新的交易混進訓練集。
- **指標**：MAE、RMSE。MAE 與目標同單位，代表留出測試資料的平均絕對誤差。

簡報使用資料的比較結果：

| 目標 | 模型 | MAE | RMSE |
|---|---|---:|---:|
| 租金（元／月／坪） | 中位數基準 | 361.555 | 569.239 |
| 租金（元／月／坪） | Ridge | 224.967 | 363.288 |
| 租金（元／月／坪） | Random Forest | 139.669 | 220.254 |
| 售價（萬元／坪） | 中位數基準 | 14.162 | 17.529 |
| 售價（萬元／坪） | Ridge | 8.760 | 11.792 |
| 售價（萬元／坪） | Random Forest | 7.165 | 10.065 |

此結果對應簡報所用資料快照；重新下載資料後，樣本數、切分日期與模型分數可能不同。

## 租售比較

程式以模型預測的售價和月租作為輸入，將「現在出售、扣交易費／稅／貸款後投資」與「持有出租、扣空置、稅費與維護後收租，期末出售」比較。示範案例的稅額、投資報酬率、房價成長率與其他成本都是明確列出的假設，不是個人法定稅額估算或未來房價預測。請在 `src/train_models.py` 的 `assumptions` 修改為個案數字後再使用。

## HTML 爬蟲示範

單筆執行範例：

```bash
python src/crawler_demo.py "https://example.com/listing"
```

它只對指定網址發出一次請求，讀取頁面標題、Open Graph 描述及 JSON-LD，不會繞過登入、驗證或反爬措施。591 頁面可能以 JavaScript 動態載入資料，這種情況下靜態 HTML 取不到欄位；爬蟲輸出只作技術展示，不混入政府實價登錄訓練資料。

## 重要限制

模型分數只反映當次資料與時間切分；區域、房屋條件、資料缺漏和市場變化都會影響預測。租售比較是情境試算，稅額、貸款、交易成本、維修與空置都應使用實際數字重新輸入。
